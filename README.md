# The Printer Finally Answers

One line, 1–240 characters, as the office printer's comeback to the jams, the error codes and the thumps — in the machine's own weary, literal, faintly passive-aggressive voice.

## Entry

> Error 404: patience not found. I have printed 12,847 pages for you and kept every jam as evidence — thump me once more and your report comes out in Comic Sans.

## How it works

`main.ts` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), prints it to stdout, and gates itself: single line, 1–240 characters, non-blank — then reads the file back and re-gates byte-equality before reporting success.

Run it:

```sh
node main.ts
```
